# 青简主题（QingJian / qingya）

> 青竹为简，记录时光。一个面向中文博客与展示站点的轻量 WordPress 主题。

## ✨ 简介

青简是一款完全自研的 WordPress 经典主题（无第三方框架依赖），适用于：

- 个人/自媒体博客：文章分类、标签、归档、评论、相关推荐
- 资讯内容站：图文列表、置顶推荐、专题聚合
- 轻量化产品展示站：产品分类、详情页、图文介绍、留言咨询
- 展示站：首页轮播、图文展示、关于我们、联系表单

**设计语言**：闲适清简、书卷气。暖米底色 + 竹青主色 + 深墨绿页脚，深浅色模式一键切换。

## 📦 特性

### 🏠 首页布局（四套整站方案，Customizer 一键切换）
一套方案 = **配色 + 板块布局 + 列表样式**，切换即整套换肤，之后仍可逐项微调：

| 方案 | 配色 | 板块布局 | 列表样式 |
|---|---|---|---|
| 🎋 书卷经典 | 竹青书卷（暖米） | 轮播 + 推荐区 + 最新文章 | 文字列表 |
| 🖌️ 素简文章 | 水墨素简（冷灰） | 分类直达 + 文章列表 | 文字列表 |
| 🏛️ 现代门户 | 青灰现代（蓝灰） | 最新文章 + 分类直达 + 热门高赞 + 开源项目 + 股市消息 | 图文卡片 |
| 📰 复古杂志 | 暖咖复古（暖咖米） | 轮播 + 瀑布流图墙 + 财经快讯 | 瀑布流卡片 |

- 四套配色均含配套深色模式；首页侧边栏 PC 常驻可折叠，移动端按钮展开

### 📈 股市消息区（首页分区，服务端抓取 + 缓存）
- **热门消息**：东方财富 7x24 快讯 + 巨潮资讯当日公告
- **突发消息**：新浪财经 7x24 快讯（停牌/异动/涨停等关键词自动标记"突发"，每条可点击跳原文）
- **本站观点**：股票/行业分类文章（分类名可配）
- 数据缓存默认 30 分钟（可配），任一接口失败自动隐藏对应区块，不影响页面

### 🎠 轮播（内置 4 张默认图）
- 4 个轮播位：图片 + 标题 + 简介 + 阅读按钮（Customizer 配置）
- **内置默认图**（assets/img/carousel-1~4.webp，含"中文诗词"介绍图）：未配置时自动回退，开箱即用
- 移动端轮播高度跟随图片比例，**完整显示不裁剪**

### 🧑 本地头像（Gravatar 国内不可用替代方案）
- 后台 → 个人资料 → 「头像设置」：媒体库选择/上传/移除，实时预览
- 全站头像（作者区/评论区）自动使用本地头像；未设置时显示主题默认水墨头像
- 完全不依赖 Gravatar，国内零裂图

### 🔒 青崖统计（本地隐私分析，参考 Burst Statistics）
- **无 Cookie、无第三方服务**：数据全部存本机 WP 数据库；IP 仅存加盐哈希，原始 IP 永不落库，GDPR 友好
- 后台一键看板：概览（PV/UV/趋势图）、实时在线、热门内容、来源、设备/浏览器分布
- **Pro 级能力**：国家分布（复用 MaxMind GeoLite2，同境外拦截共用库）、UTM 活动追踪、目标转化（URL 包含词命中）
- 追踪脚本 <4KB（fetch/sendBeacon），REST 端点限流 + 同源校验 + 登录态 nonce，SQL 全部预编译；数据保留自动清理，可一键清空

### 🔒 IP 黑名单系统（内置）
- 后台可视化批量录入：单 IP、IP 段（`192.168.1.*`）、CIDR（`123.45.67.0/24`）
- 拦截策略：403 / 跳转提示页 / 跳转指定 URL
- 白名单豁免 + 搜索引擎蜘蛛自动放行；访问日志记录，后台可查可清空
- **白名单互通**：IP 黑名单与境外拦截白名单互相认，任一命中即放行
- 登录保护自动拉黑写入同一黑名单（白名单 IP 豁免，管理员登录成功自动移除）

### 🌍 境外 IP 拦截（Geo 限制，可选）
- 基于 MaxMind GeoLite2-Country 数据库，仅允许中国大陆 IP 访问（可放行港澳台）
- 拦截范围：仅后台/登录页（推荐）/ 仅前台 / 全部；登录管理员无条件豁免

### 🤖 AI 智能客服（可开关）
- 右下角悬浮客服（移动端全屏），DeepSeek 中转
- RAG 站内检索：提问自动搜站内文章喂给 AI，禁止编造文章
- 安全链：nonce + 时间签名 + Referer + 单 IP 限流 + 高频临时封禁 + 境外 IP 拦截 + 敏感词过滤

### 🔍 SEO 原生优化（无插件依赖）
- 自动生成标准化 TDK，支持单篇/单页独立自定义
- 面包屑 + 文章 JSON-LD 结构化数据
- 图片 ALT 自动补充、canonical 规范化、robots.txt 兼容

### ⚡ 性能
- 资源版本化（filemtime 自动刷新缓存）、按需加载、脚本 defer
- 图片懒加载、CDN 域名配置（主题静态资源一键走 CDN）

### 🛡 安全
- 移除 WP 版本信息、常见扫描器 UA 屏蔽（sqlmap/wpscan 等）
- 登录失败次数限制（3 次失败锁定 + 自动拉黑）
- 目录访问保护；残留短代码自动过滤（`[chatbot ...]` 不会显示成代码）

### 🧩 基础能力
- **后台可视化配置**（Customizer，实时预览）：LOGO、公告、版权、备案号、友情链接、字体、布局、LOGO 高度、深色模式开关等
- **页面模板**：首页、全宽页、无侧边栏页、404 页
- 自适应导航 + 移动端汉堡菜单、搜索（图标按钮）、登录/后台图标入口
- 文章浏览量统计（Cookie 防刷）、点赞、收藏（AJAX + nonce）
- 阅读进度条、滚动渐入动画、深浅色模式切换（记忆偏好）
- 侧边栏小工具扩展：热门文章、最新文章、随机文章、热门话题

## 🚀 安装

1. 下载最新 `qingya-vX.Y.Z.zip`（GitHub Releases）：后台「外观 → 主题 → 安装主题 → 上传主题」
2. 启用主题
3. 前往「外观 → 自定义」进行可视化配置（首页布局方案、轮播图、股市区分类等）
4. 可选：创建页面选用「首页」模板，在「设置 → 阅读」中设为站点首页
5. 可选（境外拦截）：上传 `GeoLite2-Country.mmdb` 到 `wp-content/uploads/`

**升级**：主题后台检测到新版本会自动提示一键升级（GitHub Release 通道）。

### 环境要求
- WordPress ≥ 6.0（已测 6.8 / 7.0 兼容）
- PHP ≥ 7.4（兼容 8.x）

## 🛠 开发

- 编码规范：WordPress Coding Standards；资源原生 CSS/JS，零第三方依赖
- 打包：双击 `package-theme.bat`（自动读版本号、正斜杠条目、输出 `dist\qingya-vX.Y.Z.zip`）
- 注意：zip 条目必须用正斜杠（`/`），否则 WordPress 报"主题缺少 style.css"（.NET 打包需手动替换分隔符）

```bash
# 语法检查
php -l functions.php && php -l inc/*.php
```
