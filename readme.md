# 青简主题（QingJian / qingya）

> 青竹为简，记录时光。一个面向中文博客与展示站点的轻量 WordPress 主题。

## ✨ 简介

青简是一款完全自研的 WordPress 经典主题（无第三方框架依赖），适用于：

- 个人/自媒体博客：文章分类、标签、归档、评论、相关推荐
- 资讯内容站：图文列表、置顶推荐、专题聚合
- 轻量化产品展示站：产品分类、详情页、图文介绍、留言咨询
- 展示站：首页轮播、图文展示、关于我们、联系表单

**设计语言**：闲适清简、书卷气。暖米底色 + 竹青主色 + 深墨绿页脚，深浅色模式一键切换。

## 📦 特性

### 🏠 首页布局（四套整站方案，Customizer 一键切换）

一套方案 = **配色 + 板块布局 + 列表样式**，切换即整套换肤。支持：书卷经典 / 现代门户 / 极简杂志 / 水墨素简，首页板块可排序（轮播、最新文章、分类直达、热门高赞、开源项目、股市消息、侧边栏）。

### 🤖 内置 AI 能力

- **AI 智能客服**：前台悬浮对话面板，OpenAI 兼容接口
- **AI 自动博客**：与 A-Blog 插件配合，支持全自动选题、写作、配图、定时发布

### 🛡️ 异常访问防护（Attack Guard）

针对线上真实攻击场景内置自动化防护：

- 全站请求频率限制：单 IP 超阈值自动临时封禁，连续 3 次转永久黑名单
- **评论五道闸**：无意义检测 / 垃圾词 / 外链检测 / 推广意图 / 外语字符兜底
- **垃圾评论 IP 累计拉黑**：同一 IP 累计 2 次评论判垃圾 → 直接临时封禁
- XMLRPC 掐断（双重保险）、wp-login 爆破防护、境外 IP 拦截（可选）
- 评论审批策略：管理员免审、垃圾保持垃圾、超频强制人工审核

### 🧑‍🎨 本地头像（Gravatar 替代）

国内不可达环境下评论/用户头像全部本地化：用户资料页可上传自定义头像，AI 评论自动生成确定性 SVG 头像，与其他插件（星河 AI 工具箱 / A-Blog）头像机制兼容协作。

### 📊 其他

- 本地隐私统计（青崖统计：浏览量/访客，不依赖第三方）
- 网站统计侧边栏小工具、热门话题（兼容 A-Blog thread / 星河 xhai_thread）
- 股市消息板块（东财快讯）、默认轮播 4 张（含诗词站介绍图）
- 主题自动更新：后台「外观 → 检查主题更新」（GitHub Release 通道，api.github.com 直连）

## 🚀 快速开始

1. 下载最新 Release（`dist/qingya-vX.Y.Z.zip` 或 GitHub Releases）
2. 后台 → 外观 → 主题 → 上传安装 / 启用
3. 外观 → 自定义：配色、首页布局、板块开关

## 🔄 更新机制

- 后台「外观 → 检查主题更新」手动触发（绕过 WP 12h 缓存）
- 更新源为 GitHub Release asset，通过 api.github.com 直连下载（github.com 被墙环境下可用）
